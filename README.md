# GTA5RP Launcher limplxx

Лаунчер для Windows с выбором серверов, входом в аккаунт GTA5RP, новостями и автоматическими обновлениями.

## Установка

Скачайте установщик из [последнего релиза](https://github.com/kerryL1ner/launcher/releases/latest), установите приложение и войдите в свой аккаунт. В настройках укажите папку уже установленного RAGE MP.

Начиная с 1.4.0, при запуске лаунчер проверяет обновления в этом репозитории, скачивает новую версию и перезапускается после установки. Версии до 1.4.0 нужно обновить вручную один раз. Приложение запрашивает права администратора через обычное подтверждение Windows.

GTA V и RAGE MP устанавливаются отдельно. В релизах находятся файлы приложения; пользовательские пароли, сессии и настройки в них не включены.

Данные аккаунта и настройки сохраняются локально.

review: https://youtu.be/CZoBbXeFOkw

## Безопасность

Лаунчер хранит данные для входа локально и никуда их не передает.

У limplxx launcher нет собственных серверов, все данные лаунчер получает через сервера [gta5rp.com](https://gta5rp.com).
